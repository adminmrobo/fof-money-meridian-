# 돈의 경맥 — 자금순환으로 읽는 거시경제

경제학 × 회계학 해설 시리즈 · 글 **안상선** · 자료 한국은행 자금순환표·상세자금순환표

돈은 어디로 흐르고, 어디에 고이고, 어디서 막히는가? 경제순환모형·IS-LM·AD-AS를 회계의 세 장부(손익계산서·재무상태표·현금흐름표) 비유로 자금순환표와 잇고, 한국은행 통계로 2025~2026년 한국 경제의 돈의 흐름을 출처와 함께 읽습니다. 박사 · 조수(하루) · 초파리 연구원 · 주판봇이 진행하는 단일 HTML 인터랙티브 해설입니다.

## 한 편에 들어 있는 것

1. **히어로** — 질문, 핵심 숫자(KPI), 네 캐릭터의 첫 대화
2. **큰 그림** — 이 편이 자금순환 통계의 어느 수준을 보는지
3. **5칸 사다리** — 일상 비유 → 모형 → 실험(슬라이더·시뮬레이션) → 실제 통계 → 지금의 점검. 칸마다 확인 퀴즈
4. **대결** — 초파리 연구원(의심하는 쪽)과 주판봇(확신하는 쪽)이 결과를 걸고, 같은 모형으로 판정
5. **정리** — 칸별 비교표, 앞뒤 편과 이어지는 것, 비유의 한계
6. **지식 색인과 꾸러미** — 검색 가능한 색인과 연결 그래프, JSON-LD·Turtle·CSV·BibTeX·RIS 내려받기
7. **출처 표** — 숫자별 출처와 확인일

## 편마다 다루는 내용

**01 돈의 경맥**
- 경제순환모형 → IS-LM → AD-AS → 부문수지 항등식(국내 순자금운용 합 = −국외) → 잔액표의 평가 변동
- 회계 비유: 손익계산서 ↔ 생산·소득계정(GDP·분배), 현금흐름표 ↔ 자금순환표(금융거래표), 재무상태표 ↔ 금융자산부채잔액표·국민대차대조표, 미실현 평가손익 ↔ 평가 변동
- 진단 카드: 실물과 명목의 괴리, 반도체 이익 집중, 지역 집값, 가계 금융자산
- 환류 시나리오: 반도체 2사 영업이익 → 가계 소득 → 소비, 주가 평가이익 → 부의 효과

**02 누가 누구에게**
- 상세자금순환표(보유자 × 발행자 × 상품, 2018년~ 연간)
- 장난감 경제의 거래상대방 행렬과 중개 투시 실험
- 2024년 말 상호연계비율(은행-가계 13.9% 등)과 한국은행 해석
- 2026년 2분기 가계 예금 −23.3조, 주식·펀드 +101.6조

**03 금융기관끼리**
- 금융법인 다섯 분류와 금융기관 간 연계(2024년 말 3,477.5조, 8.9% 증가)
- 환승 모형: 연계 = 100 × k ÷ (1 − k), (I − F)⁻¹
- 전염 실험: 고리형·완전 연결·두 무리, 충격 크기에 따라 뒤바뀌는 연결의 역할(상전이)
- 2026년 상반기 금융안정보고서 지표(FVI 46.0, 신용융자·신용미수 39.4조 등)

## 출처 원칙

- 숫자마다 근거 칩: **1차 자료**(기관 원문), **보도**(기관 발표를 전한 언론 보도), **기준일**(통계 시점)
- 장난감 모형과 가정값은 **설명용 모형**, 실제 통계는 **실제 통계** 도장으로 구분하고, 필자 계산·해석·추정은 본문에 따로 표시
- 모든 편은 원문 대조 검증과 페르소나 다관점 검수를 거침
- 이 시리즈는 교육용이며 투자 자문이 아닙니다. 잠정치는 개정될 수 있습니다
